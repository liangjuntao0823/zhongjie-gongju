# 中介工具

房产中介综合管理 iOS 应用，基于桌面"成交-收租表"功能开发。

## 功能模块

### 首页看板
- 在租房源统计
- 本月应收/已收租金
- 本月中介费收入
- 包租盈亏汇总
- 收租进度条
- 即将到期房源提醒
- 快捷操作入口

### 成交管理
- 成交记录（日期、房号、房东、户型、租期、租金、押金、中介费等）
- 杂项收入记录
- 杂项支出记录

### 收租管理
- 普通房源收租
- 包租/托管房源收租
- 月度收租状态标记
- 季度水电结算标记
- 房源详情（水电底数、租期等）

### 包租打租
- 包租房源打租记录
- 月度打租状态
- 年租金、付款方式管理

### 包租盈亏
- 包租成本计算（日成本、空置成本）
- 租金收入计算
- 净利润/亏损状态
- 剩余包租成本

### 水电结算
- 电费计算（总表/分表/底数 × 单价）
- 水费计算
- 预存结算
- 结算单生成

## 技术栈
- SwiftUI
- SwiftData（本地数据持久化）
- iOS 17.0+

## 数据联动
- 首页看板数据实时来源于各模块
- 成交记录中的房源可关联到收租管理
- 包租盈亏与打租记录互相关联

## 编译
通过 GitHub Actions 自动编译为 IPA（免签名版本）。
